Excel and Power BI Mini Project

Project Overview

This mini project demonstrates data cleaning, data analysis, and data visualization using Microsoft Excel and Power BI.

Objectives

- Clean and organize raw data.
- Perform data analysis using Microsoft Excel.
- Create meaningful charts and visualizations.
- Build an interactive dashboard using Power BI.
- Present insights in a clear and professional format.

Tools and Technologies

- Microsoft Excel
- Microsoft Power BI
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development

Project Files

- Excel Workbook: Excel analysis and data cleaning.
- Power BI Report: Interactive dashboard (".pbix").
- PDF Report: Exported dashboard for easy viewing.
